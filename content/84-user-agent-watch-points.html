The question

Written in 1999, this note begins by insisting that a term of art is not merely a term of art:

Browsers and Email programs are user agents. This isn't just a formal long term for them, it is an important issue. They are programs which act on behalf of, and represent, the user. User Agent Watch Points, 1999

And states the duty that follows, in the form of a warning:

The computer protocols such as HTTP are defined to carry a particular meaning, and it behooves a user agent to representthat meaning to the user, or the whol system of peeople and machines breaks. User Agent Watch Points, 1999

Chapter 20 established that the meaning travels up the stack. This says somebody has to deliver it at the top.

84.1 Two redirections that mean opposite things

The distinction matters because the two addresses carry different promises. The institution has made a persistence commitment for one and not for the other, which is Chapter 3’s argument about where information in a name comes from, appearing as a question about which address a person copies down.

84.2 The commitment the interface hides

The second watch point is about the distinction of Chapter 2, and Berners-Lee asks for it to be visible:

A graphic client, for example, should use a very different cursor while the user is hovering over a POST button to when the user is hovering over a GET link. User Agent Watch Points, 1999

And then makes the analogy that gives the requirement its force:

Doing a POST is like sending an email. User Agent Watch Points, 1999

From which the missing feature follows. Everyone expects to be able to look at what they have sent, because those are the things they are committed to. The same should be true of forms:

The web client should keep a record of POSTs which have been submitted. User Agent Watch Points, 1999

A sent-items folder for the Web. Twenty-six years later no browser has one, and the record of what a person has committed themselves to exists only in the inboxes of the parties they committed to.

He anticipates the objection that this would waste space for sites that confuse the two methods, and dismisses it: those sites are fundamentally broken anyway and the sooner the misuse is fixed on all sides the better. Then the statement of principle:

Understanding when a commitment is made is a really important part of the user interface. Get it right. User Agent Watch Points, 1999

84.3 Hide the identifiers

The third watch point is an objective stated absolutely:

A web user should never be aware of a URI while using the Web, either creatively or browsing. User Agent Watch Points, 1999

The techniques are practical: put identifiers behind a status bar or an under-the-hood window, identify things by their titles, and add properties for short titles and icons to make that easier.

The tension with Chapter 68 is worth noticing. There, the address bar is where a person learns who they are dealing with, and Chapter 6 makes the domain name the visible seam carrying accountability. Here the identifier should never be seen. Both are right about different things: a person needs to know whose site this is, and does not need to see the path.

84.4 Why an agent is not a viewer

The word the note insists on carries a duty. A viewer displays what arrives. An agent represents someone, which means conveying what the other party has actually said, including the parts the other party would rather not emphasise.

Each watch point is a case of the browser failing to pass on a distinction the protocol took care to make. Chapter 20 showed that the chain of specifications delivers meaning to the top of the stack. If the last link drops it, the precision below was wasted.

What happened since

  • The redirection distinction was implemented and hidden. Browsers handle the two correctly for caching and bookmarks, and never show the user which occurred, so the choice of which address to share is still made blind.
  • The sent-items folder was never built. No browser records what a user has submitted, and the nearest equivalents are password managers and per-site account pages.
  • Identifiers were hidden, then partly restored. Browsers trimmed and then un-trimmed what they show in the address bar through the 2010s and 2020s, and the balance between Chapter 68’s requirement and this chapter’s remains unsettled.
  • The commitment cue never arrived. Nothing distinguishes hovering over a link that commits you from one that does not, and the consequences are absorbed by confirmation dialogues instead.
