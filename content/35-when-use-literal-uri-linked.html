The short version

In Turtle, the usual way of writing Linked Data, a web address in angle brackets stands for the thing it names; in quotation marks it is only a string of characters. When a statement is about the name itself, quote it, or a later merge of datasets will silently rewrite it.

The question

The shortest note in Volume IV, dated 5 November 2017, marked a first draft, and by its author’s own account a small point that sometimes needs careful explanation.

When you use RDF, we get used to using URIs a symbols so much that we can slip up and accidentally use it that way on one of the very rare occasions on which we are not talking about the thing the symbol represents, we are talking about the URI itself as a string. 35.1 The rule

Linked Data is RDF published on the Web so that datasets can point into one another (Chapter 49). RDF describes the world as statements, each a triple: subject, property, value. Turtle is a common way of writing those triples down. In Turtle a URI in angle brackets is a symbol: it names a thing. A value in quotation marks is a literal: a piece of text, taken as it stands. 35.2 What goes wrong, exactly

The note’s example builds up in four steps.

  1. Example.com calls Joe <https://example.com/people#Joe> and says he is a person named Joe Meadows.
  2. A university calls him <https://uni.edu/students#JRMeadows> and says he is a student.
  3. Someone states that the two are the same, using the property owl:sameAs.
  4. A system may now normalise: pick one name and use it everywhere, so the data is “smushed together”.

The figures use Turtle shorthand. A prefix stands for the start of a URI, so ex:Joe is short for <https://example.com/people#Joe>; foaf: is a common vocabulary for people; and a means “is a”. uni:, contact: and owl: work the same way; owl:sameAs is the standard ‘same as’ property.

Now Joe adds a line to his profile: he prefers to be known by the university name. That line is about a name, not about Joe, so the name must be quoted. Figure 35.2 follows both versions through the merge.

35.3 Why this is not a quirk of one notation

The mistake is a confusion of use and mention. Paris is a city; “Paris” has five letters. The first sentence uses the word to talk about a place; the second mentions the word to talk about the word. Angle brackets and quotation marks make that choice explicit.

It bites in RDF because the system may substitute equals for equals. Any system that rewrites identifiers will rewrite a mentioned name along with the used ones unless the format tells them apart. Many everyday tools do:

Where the format cannot record the difference, the rare mention is lost.

What was already in place

  • The notation was already standard. RDF 1.1 Turtle became a W3C Recommendation in February 2014, so the bracket-versus-quote syntax the note relies on was fixed three years before it was written.
  • So was the merge. owl:sameAs, the “same as” statement that licenses smushing, comes from OWL, a W3C Recommendation since February 2004.
