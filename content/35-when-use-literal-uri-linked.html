The short version

In Turtle, the usual way of writing Linked Data, a web address in angle brackets stands for the thing it names; in quotation marks it is only a string of characters. When a statement is about the name itself, quote it, or a later merge of datasets will silently rewrite it.

The question

Joe states in his profile that he would rather be known by his university address. A system later learns that his two addresses name one person and merges the records. Written the wrong way, his statement now says Joe prefers to be known as Joe. No error is reported; the preference has gone. Berners-Lee wrote a 2017 note to prevent this slip, “a little point which sometimes needs careful explanation”.

35.1 Brackets name a thing, quotes hold text

Linked Data is RDF published so that datasets can point into one another (Chapter 49). RDF describes the world as triples: subject, property, value, commonly written in Turtle. In Turtle a URI in angle brackets is a symbol: it names a thing. A value in quotation marks is a literal: a piece of text, taken as it stands. Berners-Lee offers a mnemonic for the brackets:

Anyone who has inserted a row in a spreadsheet and found a typed note “see B2” still pointing at the old cell has met this problem.

35.2 How a merge erases a preference

The note’s example builds up in four steps.

  1. Example.com calls Joe <https://example.com/people#Joe> and says he is a person named Joe Meadows.
  2. A university calls him <https://uni.edu/students#JRMeadows> and says he is a student.
  3. Someone states that the two are the same, using the property owl:sameAs.
  4. A system may now use one name everywhere: the data is “smushed together”.

In the figures, ex:Joe is short for the full example.com address, and a means “is a”.

Now Joe adds a line to his profile: he prefers to be known by the university name. That line is about a name, not about Joe, so the name must be quoted. Figure 35.2 follows both versions through the merge.

35.3 Paris and “Paris”

The mistake is a confusion of use and mention. Paris is a city; “Paris” has five letters. The first sentence uses the word; the second mentions it. Angle brackets and quotation marks make that choice explicit.

It bites in RDF because the system may substitute equals for equals. Any system that rewrites identifiers will rewrite a mentioned name along with the used ones unless the format tells them apart. Many everyday tools draw the same line:

Where the format cannot record the difference, the rare mention is lost. The note ends: “Hence this whole DesignIssues note just to make the point.”

What was already in place

  • The notation was already standard. RDF 1.1 Turtle became a W3C Recommendation in February 2014.
  • So was the merge. owl:sameAs, which licenses smushing, comes from OWL, a W3C Recommendation since February 2004.
