Chapter 83

Intuitive hypertext editing

1998

Source Intuitive hypertext editing, a Design Issues note by Tim Berners-Lee, 1998-04-01. read the original

The question

The companion to Chapter 82, written in April 1998, and it opens with the sentence that has been quoted at every discussion of the read-write Web since:

If you think surfing hypertext is cool, that's because you haven't tried writing it. Cleaning up the User Interface 2: Hypertext editing, 1998

The diagnosis that follows is sharper than the complaint. People’s bookmarks became important to them, he says, because they had learned to put up with the simplest form of hypertext editing there is, as a compromise.

83.1 Counting the clicks

The method is a measure suggested by Dan Connolly: count the actions, with a penalty of ten when the user has to invent a filename or an identifier. The penalty is the interesting part, because it prices thinking rather than doing.

83.2 No mode, no location

The two assumptions are stated as a heading that is a joke and a requirement that is not:

A first assumption, by the way, is that you have modeless interface in which browsing and editing are not separate functions. If to edit a page, you have to switch from browsing mode to editing mode, then you have lost already. Cleaning up the User Interface 2: Hypertext editing, 1998

The losses compound. Switching mode loses once. Having to invent a local filename loses twice. Answering questions about where to save links loses again and has probably damaged the file. And the principle underneath all three:

You should not have to think about "where" things are. Cleaning up the User Interface 2: Hypertext editing, 1998

That is Chapter 82’s location fixation, stated as a demand on the editor rather than as an observation about the file system.

83.3 The operations he wants

Three are described, and each is a thing people still do by hand.

Make a new linked node. Select a phrase, one keystroke, and a new document appears from a template, already linked from the phrase, with the cursor waiting. Berners-Lee marks the one remaining step with a sad face: the dialogue asking where to save it.

Annotate something you cannot write to. Create a note where you do have permission, make a label pointing at it, and store the label on a server that serves labels about other people’s pages. The mechanism is Chapter 77’s, used for commentary rather than for filtering.

Excerpt. This is the one he says nobody has built:

Copy to the clipboard a BLOCKQUOTE with inside it a copy of the selected text, linked back to the original document from which it came. Make the link to an existing anchor in the document if one is there, or else a new one if one can be made, or else the document as a whole failing that. Cleaning up the User Interface 2: Hypertext editing, 1998

Quote something and have the quotation carry its own provenance, as precisely as the source allows, with a graceful fallback. Every chapter of this book does that operation, by hand, with a script to check the result.

83.4 Why the note ends with a screenshot

The last item on the list is deliberately mundane:

It's always nice to be able to grab a screen shot or a video frame and insert it into the minutes you are taking of a meeting -- but how many keystrokes does it take? Cleaning up the User Interface 2: Hypertext editing, 1998

The measure is the same throughout, and it is why the note works as criticism. Not whether a thing is possible, but how many steps it takes, counted honestly, including the steps where you have to stop and think of a name.

What happened since

  • Modeless editing arrived, inside applications. Editing in place became normal in documents, wikis and note systems, and did not become a property of the Web itself.
  • Naming was abolished. Automatic titles and generated identifiers removed the ten-click penalty in most modern tools, which is the single biggest improvement since the note.
  • Excerpt still is not built. Copying a passage with a link back to its exact location remains manual, though text fragments, which shipped in 2020, finally supply the addressing it needs.
  • Annotation layers were built repeatedly. Systems for commenting on pages one does not control have been created many times and none has become general, which is the same fate as the labelling system of Chapter 77.

Connections
